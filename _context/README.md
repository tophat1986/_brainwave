# _context

This directory stores condensed state summaries generated by the engine when an expressed DNA document group reaches 100% completion. Summaries are namespaced by the module's canonical four-letter identity.

Examples:

- `_DNA-SAPP/00200_state.md`
- `_DNA-BRND/00300_state.md`

Agents should read `_my_brainwave_north_star.md` first for current direction, then use the relevant summary here for local recall.
