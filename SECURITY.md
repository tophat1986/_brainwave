# Security Policy

## Supported Version

Until _brainwave reaches `1.0.0`, only the latest published `0.x` release is supported.

## Reporting a Vulnerability

Do not disclose a vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when available. If it is not enabled, open a public issue requesting a private contact channel without including exploit details.

_brainwave hooks execute repository-local JavaScript with the permissions of the selected agent tool. Review hook definitions before trusting them, and use _brainwave only from repositories whose contents you trust.
